# Python Inventory Management System

A simple inventory management system developed in Python to manage products, stock quantities, and inventory financial values.


## Features

- Display a list of products.
- Show product prices and stock quantities.
- Calculate the value of each product in stock.
- Calculate the total financial value of the inventory.
- Count products with stock below 5 units.
- Count products with stock of 5 or more units.
- Identify the most expensive product.
- Generate an inventory summary report.


## Technologies Used

- Python 3


## How to Run

1. Install Python 3.
2. Clone this repository.
3. Run the following command:

```bash
python sistema_de_gestao_de_inventario.py
```
